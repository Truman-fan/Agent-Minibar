# Agent Minibar modifications

Agent Minibar is an independently maintained derivative of
[Codex Minibar](https://github.com/vertopolkaLF/codex-minibar), originally
developed by Pavel Leontyev (`@vertopolkaLF`). It is not an official release of
the upstream project.

The derivative is maintained by
[Truman_show](https://github.com/Truman-fan). Its source repositories are:

- GitHub (primary): <https://github.com/Truman-fan/Agent-Minibar>
- Gitee (mirror): <https://gitee.com/Truman-fan/Agent-Minibar>

Material changes from the upstream project include:

- a Windows floating quota-ring surface with compact provider quota cards;
- one or two independently assignable floating provider circles;
- additional domestic-provider and CLI-provider adapters;
- provider ordering and quota appearance customization;
- Windows interaction, outside-click dismissal and rendering fixes;
- Agent Minibar application, packaging, repository and update identities; and
- package-size and runtime-asset cleanup.

The Git history is retained so individual changes and upstream authorship can
be audited. Provider names and logos identify compatible third-party services;
they do not imply affiliation or endorsement.
