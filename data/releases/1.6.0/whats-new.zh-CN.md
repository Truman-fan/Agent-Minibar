## Agent Minibar 1.6.0

首个 Agent Minibar 社区版本加入了可自定义的 Windows 悬浮额度圈、可分别选择提供商的双悬浮圈、国内与 CLI Agent 适配，以及更清楚的额度不可用状态。

- 完成应用品牌迁移，并安全复制已有 Codex Minibar 设置
- 优先使用 GitHub 更新源，失败时回退到 Gitee，并强制校验 SHA-256
- 提供 Windows x64 便携 ZIP；请完整解压后运行 `agent-minibar.exe`

当前便携包尚未进行代码签名。Windows 可能显示 SmartScreen 提示，运行前请核对发布页面提供的 SHA-256。
