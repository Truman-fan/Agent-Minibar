## Agent Minibar 1.6.0

The first Agent Minibar community release adds configurable Windows floating quota circles, one or two independently selected providers, domestic and CLI provider adapters, and clearer quota availability states.

- Rebranded application and safe migration of existing Codex Minibar settings
- GitHub primary updates with a Gitee fallback and required SHA-256 verification
- Windows x64 portable ZIP; extract the whole folder and run `agent-minibar.exe`

This portable build is currently unsigned. Windows may show a SmartScreen warning; verify the published SHA-256 before running it.
