# Agent Minibar 1.6.0

## 中文说明

这是 Agent Minibar 的首个社区发行版。本次先提供 **Windows x64 便携 ZIP**，适用于绝大多数 Intel / AMD Windows 10、Windows 11 电脑。

使用方法：

1. 下载 `agent-minibar-1.6.0-x64-portable.zip`；
2. 对照 `SHA256SUMS` 验证文件；
3. 完整解压 ZIP；
4. 运行目录中的 `agent-minibar.exe`。

请勿直接在压缩包内运行，也不要只复制 EXE。当前程序尚未购买代码签名证书，Windows 可能显示 SmartScreen 提示；请确认下载来源和 SHA-256 后再运行。

主要变化：

- Windows 单/双悬浮额度圈及紧凑额度信息卡；
- 提供商选择、排序、颜色与渐变自定义；
- DeepSeek、Qwen Code、Kimi Code、豆包 / 火山方舟、智谱 GLM、MiniMax、百度千帆、腾讯混元等适配基础；
- GitHub 主更新源与 Gitee 备用更新源；
- 旧 Codex Minibar 设置的无损复制迁移；
- 自动更新包必须通过 SHA-256 校验。

## English

This is the first Agent Minibar community release. It initially ships as a **Windows x64 portable ZIP** for most Intel/AMD Windows 10 and Windows 11 PCs.

Download the ZIP, verify it against `SHA256SUMS`, extract the complete folder, and run `agent-minibar.exe`. The binary is currently unsigned, so Windows may show a SmartScreen warning.
